# Executive Sales Performance Dashboard (Power BI)

## 📌 Project Overview
Developed an end-to-end Business Intelligence solution to transform fragmented transactional sales data into an interactive, executive-ready performance dashboard. The final report enables stakeholders to track total revenue stream health, analyze category drivers, and monitor chronological trend performance seamlessly.

## 🛠️ Technical Architecture & Toolkit
* **BI Platform:** Power BI Desktop
* **Data Modeling:** Star Schema Design (1:Many Relationships)
* **Data Engineering:** Engineered a dedicated custom **DAX Calendar Dimension Table** to support scalable time-intelligence calculations.
* **Calculations:** Formulated explicit custom **DAX Measures** for clean core financial aggregations (SUM).
* **UI/UX Design:** Implemented executive layout grids, conditional formatting color gradients, dynamic category cross-filtering, and metric slicers.

## 📊 Key Insights Extracted
* **Primary Revenue Driver:** The "Electronics" category vastly outpaces "Accessories," contributing the overwhelming majority ($0.62M out of $0.65M) of overall organizational revenue.
* **Operational Velocity:** Total volume successfully closed at **67 units sold** across active transactional windows.
* **Time-Series Peak:** Identified a critical revenue spike concentrated directly within the May operational timeline, climbing to a unified peak of **$644K**.
